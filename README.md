# Digital-Signal-Processing

MATLAB project covering fundamental Digital Signal Processing (DSP) concepts such as FFT analysis, digital filtering, frequency response analysis, pole-zero analysis, and audio denoising.

The project includes practical implementations and simulations using MATLAB for sinusoidal signal filtering, discrete-time system analysis, and noisy audio processing.


## Project Structure

```
│
├── figures/        # Generated plots and figures
├── audio/          # Audio files used for processing

```
